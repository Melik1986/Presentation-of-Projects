## Быстрая настройка (5 минут)

### Шаг 1: Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
bun install
```

**Нет Bun?** Используйте npm:
```bash
npm install
```

### Шаг 2: Запуск сервера разработки

```bash
bun dev
```

Откройте http://localhost:3000 в браузере.

Вы должны увидеть 6 цветных папок с placeholder изображениями.

---

### Шаг 3: Замена изображений

Перейдите в папки `public/img/catalog-X/` (X = от 1 до 6).

**Для каждого каталога замените 7 изображений:**

**Главная страница (папки)** - вертикальные:
- `preview-1.png` (800 × 1200px)
- `preview-2.png` (800 × 1200px)
- `preview-3.png` (800 × 1200px)

**Страницы каталогов** - горизонтальные:
- `card-1.png` (1200 × 800px)
- `card-2.png` (1200 × 800px)
- `card-3.png` (1200 × 800px)
- `card-4.png` (1200 × 800px)

**Советы:**
- Используйте формат JPG или PNG
- Оптимизируйте изображения (рекомендуется: < 500KB)
- Сохраняйте те же имена файлов

---

### Шаг 4: Редактирование контента

Откройте `content/catalogs.json` в любом редакторе кода.

#### Обновите главную страницу (строки 3-6):

```json
"homepage": {
  "title": "Ваше Имя",  ← Замените на ваше имя
  "description": "Замените на ваш профессиональный статус..."  ← Ваше описание
}
```

#### Обновите каждый каталог:

Найдите каждый каталог (всего 6) и обновите:

**Пример для Каталога 1 (Веб-разработка):**

```json
{
  "id": "web-development",  ← Не меняйте
  "name": "Web Development",  ← Название папки на главной
  
  "content": {
    "cards": [
      {
        "index": "01",
        "title": "E-Commerce Platform",  ← Название вашего проекта
        "description": "Замените на описание..."  ← Ваше описание
      }
    ]
  }
}
```

Повторите для всех 4 карточек в каждом каталоге.

### Шаг 5: Настройка цветов (Опционально)

В `content/catalogs.json` у каждого каталога есть секция `"theme"`:

```json
"theme": {
  "folderGradient": "#C7D5E0",  ← Цвет папки (главная)
  "accentColor": "#3b82f6",     ← Акцентный цвет (страница каталога)
  "backgroundColor": "#0a0a0a"  ← Фон страницы
}
```

**Текущие цвета папок (мягкие матовые):**
- Каталог 1: `#C7D5E0` (голубой)
- Каталог 2: `#E8D4D9` (розовый)
- Каталог 3: `#D4E8D9` (мятный)
- Каталог 4: `#E0D4E8` (лаванда)
- Каталог 5: `#E8DDD4` (персиковый)
- Каталог 6: `#E8D4D4` (коралловый)

**Подберите цвета онлайн:** https://htmlcolorcodes.com/

### Шаг 6: Публикация на Vercel

1. **Создайте аккаунт Vercel** (бесплатно): https://vercel.com
2. **Установите Vercel CLI:**
   ```bash
   npm install -g vercel
   ```
3. **Соберите проект:**

4. **Задеплойте:**
   ```bash
   vercel deploy
   ```
5. **Следуйте подсказкам** - всё автоматически!

## Частые вопросы

### В: Изображения не отображаются?

**О:** Проверьте:
- Пути в `catalogs.json` должны начинаться с `/img/`
- Имена файлов должны совпадать точно (регистр важен)
- Файлы должны быть в правильной папке `catalog-X`

### В: Как добавить больше проектов?

**О:** В `catalogs.json` добавьте объекты в массив `"cards": []`:

```json
"cards": [
  { ... существующая карточка ... },
  { ... существующая карточка ... },
  {
    "index": "05",
    "title": "Новый Проект",
    "image": "/img/catalog-1/card-5.png",
    "description": "Описание нового проекта"
  }
]
```

### В: Как отключить аудио?

**О:** В `catalogs.json` установите track в null:

```json
"track": null
```

### В: Можно добавить больше категорий?

**О:** Да! Скопируйте существующий каталог и:
- Измените `"id"` на уникальное значение
- Создайте папку `public/img/catalog-7/`
- Добавьте 7 изображений
- Обновите контент

### В: На мобильном видны 6 папок?

**О:** По дизайну, на мобильных показываются только первые 4 папки чтобы избежать переполнения. Это автоматически.

### В: Как изменить название папки?

**О:** В `catalogs.json` отредактируйте `"folder.displayName"`:

```json
"folder": {
  "displayName": "мои работы",  ← Меняет текст на папке
  "variant": "variant-1"
}
```

### В: Что-то сломалось?

**О:** Попробуйте:
1. Удалите папку `.next`
2. Запустите `bun dev` снова
3. Обновите браузер с очисткой кэша (Ctrl + Shift + R)
