# Starlight Portfolio

Modern portfolio website built with Next.js 15, React 19, and TypeScript.

## 🚀 Tech Stack

- **Framework:** Next.js 15 (App Router)
- **UI Library:** React 19
- **Language:** TypeScript (Strict Mode)
- **Styling:** CSS Modules
- **Animations:** GSAP, Lenis
- **Architecture:** Feature-Sliced Design

## 📁 Project Structure

```
starlight/
├── src/
│   ├── app/          # Next.js App Router
│   ├── shared/       # Shared utilities, UI, types
│   ├── entities/     # Business entities
│   ├── features/     # Feature modules
│   └── widgets/      # Composed widgets
```

## 🛠️ Development

```bash
# Install dependencies (using Bun)
bun install

# Run development server (with Turbopack)
bun dev

# Build for production
bun run build

# Start production server
bun start

# Lint code
bun run lint

# Format code
bun run format

# Type check
bun run type-check
```

### Why Bun?

- ⚡ **~10x faster** package installation
- 🚀 **Native TypeScript** support
- 📦 **Built-in bundler** and test runner
- 🔒 **Better security** with lockfile
- 💾 **Smaller disk usage**

## 📦 Features

- ✨ Sticky Cards Animation
- 🎨 Wildyriftian Effects

- 🎯 Feature-Sliced Design Architecture
- 📱 Fully Responsive
- ⚡ Performance Optimized

## 🏗️ Architecture

This project follows Feature-Sliced Design principles:

- **app/** - Next.js routing and layouts
- **shared/** - Reusable utilities and components
- **entities/** - Business logic entities
- **features/** - Self-contained feature modules
- **widgets/** - Complex UI compositions
